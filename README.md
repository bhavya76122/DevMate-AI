# DevMate AI 🤖

### AI-Powered Software Engineer Assistant

DevMate AI is a full-stack AI-powered developer assistant designed to help software developers with coding, debugging, SQL generation, resume analysis, documentation, and interview preparation.

It combines a modern React frontend with a FastAPI backend and a locally running Ollama AI model.

---

## 🚀 Features

- 💬 **AI Chat** – Chat with an AI software engineering assistant
- 💻 **Code Generator** – Generate code based on requirements
- 🐞 **Bug Detector** – Identify and explain bugs in code
- 🗄️ **SQL Generator** – Generate SQL queries from natural-language requirements
- 📄 **Resume Analyzer** – Analyze resumes and provide suggestions
- 📚 **Documentation Assistant** – Generate and understand technical documentation
- 🎯 **Interview Questions** – Practice technical interview questions
- 📑 **PDF Upload** – Upload PDF documents for AI-assisted analysis
- 🔐 **User Authentication** – Login and registration using JWT
- 💾 **Chat History** – Save and restore previous conversations
- 🌙 **Dark/Light Theme** – Theme switching support
- 📋 **Copy Responses** – Easily copy AI-generated responses
- 📝 **Markdown Support** – AI responses are displayed with Markdown formatting
- 👤 **User Profile** – Manage user profile information
- ⚙️ **Settings** – Application settings and preferences
